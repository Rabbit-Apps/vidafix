# Official technical guides

## Plex Media Server API

[Official Plex Media Server API documentation](https://developer.plex.tv/pms/)

Reference for local server API requests, metadata, response formats and authentication headers. Consult for the Plex adapter and, when requested, later playback work. API documentation does not expand the project's approved Phase 1 scope.

## VIDAA WebApp Development Guide

[Official VIDAA WebApp Development Technical Guide (PDF)](https://www.vidaa.com/wp-content/uploads/2020/12/WebApp_Development_Guide_for_VIDAA.pdf)

Reference for TV web applications, remote key handling, explicit focus navigation and Back/exit behaviour. This older guide is not proof of compatibility with the Hisense 55U7HAU / VIDAA 6 firmware; verify relevant behaviour on the actual TV.
